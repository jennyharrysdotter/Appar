# Appar

Jennys små mobilappar, publicerade med GitHub Pages.

- **Vad ska jag hitt på?** – förslag och evenemang i Uppsala: https://jennyharrysdotter.github.io/Appar/hitt-pa/
- **Uppsala på tallriken** – Uppsalas restauranger att bocka av: https://jennyharrysdotter.github.io/Appar/tallriken/ (listan ligger i tallriken/restauranger.json)
- **Ohuhu Blend Lab** – färgövergångar med mina Ohuhu-pennor: https://jennyharrysdotter.github.io/Appar/blend-lab/ (pennregistret ligger i blend-lab/data/pens.json)
- **Soffsamtal** – samtalsfrågor för par, vänner och familj: https://jennyharrysdotter.github.io/Appar/soffsamtal/

Varje mapp är en fristående app (index.html, manifest, service worker och ikoner).
